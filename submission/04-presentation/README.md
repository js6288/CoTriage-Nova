# CoTriage 挑战杯答辩材料

本目录保存 CoTriage 挑战杯答辩演示的正式输出、逐页讲稿和可继续编辑的 SVG 制作工程。

## 当前版本

- `CoTriage-挑战杯答辩PPT-V2.pptx`：16:9、19 页；其中前 15 页为主答辩，后 4 页为问答附录，全部页面带演讲者备注。
- `storyboard-v2.md`：19 页逐页叙事脚本，主讲建议时长为 8 分 55 秒。
- `CoTriage-PPT-V2-contact-sheet.png`：V2 全稿联系表，用于快速检查页面顺序、视觉节奏和截图清晰度。
- `rendered-v2/`：由本机 PowerPoint 重新打开后导出的 19 张逐页 PNG。
- `projects/cotriage-challenge-cup-v2_ppt169_20260809/`：V2 的设计规范、素材清单、SVG 源文件、后处理文件和逐页备注。

## 叙事结构

V2 采用“现实问题—作品亮相—运行驾驶舱—总体架构—六项核心功能—完整演示—当前运行窗口—场景扩展—创新价值”的功能展示型主线。问答附录分别解释赛事指标口径、RAISE 单事件决策、Outbox 状态机和工程部署。

`S-11` 在第 13 页以完整原图呈现，标题固定为“当前运行窗口”。答辩稿不从该截图抽取单独成绩，也不把 P95、平均时延、TTFT 或零分母比例互相替代。

## 历史版本

V1 PPT、原逐页脚本和原预览图继续保留，便于回看此前版本；当前答辩与后续修改以 V2 文件和 V2 工程为准。
