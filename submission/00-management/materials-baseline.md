# CoTriage 参赛材料责任基线

> 基线版本：V1.1；冻结日期：2026-07-29；内部材料完成日：2026-08-10。
>
> 状态：当前责任范围已冻结

## 1. 当前责任范围

材料负责人只承担以下三项任务：

1. **作品报告**：以队友的 `reports/report.md` 为只读初稿，在 `submission/01-report/report.md` 完善第二条线正文，并制作 LaTeX 工程、报告图表和最终 PDF；
2. **软件工程交付材料**：编写交付说明书、用户使用说明书、系统设计说明书、部署与运维说明书、实验与测试报告；
3. **参赛 PPT**：制作 PPTX、PDF 备份及页面使用的图表和截图。

实验数据、运行环境信息、必要日志和系统截图由开发与实验负责人提供。材料负责人负责核对口径、分析结果并将其写入上述三类成果，不负责重新执行完整实验。

## 2. 当前不承担的事项

- 参赛申报信息、申报表及团队信息的收集、填写和维护；
- 运行效果视频的脚本、录制、剪辑、字幕和成片；
- 队友服务器的部署、运维、实验重跑和大模型 API 维护；
- 最终材料投递、行政流转和压缩包制作；
- 脱敏源代码包、第三方软件与许可证清单、证据追溯表、演示异常预案、发布版代码说明、文件校验值和录屏素材清单。

如后续需要恢复上述任务，必须由团队负责人或任务委托人明确提出，并同步调整本基线、总清单和里程碑。

## 3. 目录职责

| 目录 | 定位 | 当前状态 |
| --- | --- | --- |
| `00-management/` | 责任基线、总清单和统一术语 | 当前维护 |
| `01-report/` | 作品报告 LaTeX 工程、图件和最终 PDF | 本人负责 |
| `02-engineering-docs/` | 软件工程交付材料 | 本人负责 |
| `03-evidence/` | 接收开发队友提供的实验数据和运行截图 | 外部输入 |
| `04-presentation/` | 参赛 PPTX、PDF 和配套图件 | 本人负责 |

## 4. 内容事实源

| 内容 | 当前事实源 |
| --- | --- |
| 项目总体说明 | `README.md`、队友原稿 `reports/report.md` 与第二条线事实源 `submission/01-report/report.md` |
| 系统与组件设计 | `design_doc/` 与当前代码 |
| 开发和验证记录 | `progress_doc/`，仅作内部参考 |
| 运行与排障 | `sop/`，整理后用于工程文档 |
| 实验结果与截图 | `03-evidence/` 接收的实验交接包 |
| 最终作品报告 | 内容冻结前为 `submission/01-report/report.md`；迁移后为 `submission/01-report/latex/` |

当设计文档、研发记录和当前代码存在冲突时，以当前代码、已确认部署和开发负责人确认的信息为准。没有实验数据支撑的结论不得写成实测结果。

## 5. 变更控制

冻结后只有以下情况可以调整责任范围、目录或交接格式：

1. 任务委托人明确增加或取消工作；
2. 赛题官方要求发生变化且团队负责人完成责任分配；
3. 实验数据无法按现有格式表达；
4. 发现会导致报告、工程文档或 PPT 产生事实错误的问题。

发生变更时，应同时更新本基线、`materials-checklist.md` 和受影响目录的 README，并在 Git 提交信息中说明原因。
