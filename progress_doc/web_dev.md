# Web 组件开发记录

## 日期：2026年06月22日

### 内容

1. 新增实时日志分诊大盘，并将 `/manage` 默认入口调整为 `/manage/dashboard`。
2. 在管理台左侧导航中新增“实时大盘”入口，保留原有设备管理页面。
3. 新增 8 个运行指标卡：近一分钟接入量、近一分钟推理量、Pending、P95 推理时延、异常比例、降级比例、累计推理量和 DLQ 数量。
4. 新增最近 10 分钟推理与异常数量趋势图，当前使用 CSS 柱状图，未引入额外图表库。
5. 新增日志分类分布与推理路径分布，覆盖 `NORMAL/APP_ERROR/...` 和 `RULE/CACHE/MODEL/EDGE_LLM/FALLBACK`。
6. 新增实时事件表，展示时间、设备、日志模板、分类、严重度、置信度、推理路径和时延，最多保留最近 50 条。
7. 新增 `web/src/api/dashboard.ts`，封装大盘 summary、timeseries、事件列表和 SSE 订阅接口。
8. 使用 EventSource 订阅 `/api/v1/events/stream`，显示实时流连接状态，并依赖浏览器原生能力自动重连。
9. 针对页面卡顿进行优化：SSE 事件先进入内存缓冲区，每 500ms 批量合并到表格，避免每条日志都触发 Vue 重绘。
10. 将大盘 summary 和 timeseries 刷新间隔从 5 秒调整为 10 秒，降低前端渲染与后端查询压力。
11. 更新 `design_doc/web_design.md`，补充页面结构、指标口径、数据链路、API、刷新策略、Stream 容量限制和本地验证方法。

### 验证结果

- `npm run build`：通过。
- Vite `/api` 代理已配置为 `http://127.0.0.1:8080`，REST 与 SSE 使用同源路径。
- 生产构建存在 bundle 大于 500kB 的 Vite 警告，不影响当前运行，后续可通过路由懒加载和 manual chunks 优化。
- 浏览器自动视觉检查因当前预览工具环境异常未完成，需要人工检查不同窗口宽度下的布局。

### 后续事项

1. 增加单条事件详情抽屉，展示原始日志、证据、建议、规则版本和阶段耗时。
2. 增加设备、分类、路径和时间范围过滤。
3. 对大盘进行持续高吞吐压测，确定批量刷新间隔和表格行数上限。
4. 使用路由懒加载降低首屏 bundle 体积。
